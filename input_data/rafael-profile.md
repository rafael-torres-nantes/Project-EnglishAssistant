# About Rafael Torres Nantes

AI/ML Engineer at Compass UOL (since Sep 2024), based in Campo Grande, Brazil, working remotely.
Currently finishing a Computer Engineering degree at UFMS (expected 2026).

## What he does

Builds voice AI systems in production for enterprise clients in the US — Amazon Nova Sonic,
Bedrock Agents, and Amazon Connect — plus RAG and LangChain projects. Works end-to-end, from the
application layer to the infrastructure that runs it: migrated an AI platform from EC2 to Amazon
EKS using Terraform and GitOps.

## Recent projects

  AI-driven test-drive scheduling, live agent transfer, Nova Sonic + Bedrock Agents.
- iShopMeta: migrated an e-commerce agent from text-based LangChain to asynchronous
  Speech-to-Speech with Nova Sonic.
- Scienza Health: serverless audio pipeline (Transcribe -> Bedrock -> clinical report)
  orchestrated with Step Functions and SAM, as the sole engineer on the project.
- Daasity: led the migration of the AI Analyst platform from EC2/Docker Compose to Amazon EKS.
